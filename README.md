# Harmonia Client

[English](#english) | [Tiếng Việt](#tiếng-việt)

## English

### Overview
Harmonia Client is a modern web application built with Next.js 14, featuring a rich set of UI components and advanced functionality. The project leverages the latest web technologies to deliver a seamless user experience.

### Features
- 🎨 Modern UI with Tailwind CSS and Radix UI components
- 🌐 Internationalization support with next-intl
- 🎵 Audio playback capabilities with Howler.js
- 📊 Data visualization with Recharts
- 🔐 Authentication with NextAuth.js
- 📱 Responsive design
- 🎭 Dark/Light theme support
- 🔄 State management with Redux Toolkit and Zustand
- 🎯 TypeScript for type safety
- 🎮 Drag and drop functionality with dnd-kit

### Tech Stack
- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI, shadcn/ui
- **State Management**: Redux Toolkit, Zustand
- **Data Fetching**: TanStack Query
- **Authentication**: NextAuth.js
- **Internationalization**: next-intl
- **Audio**: Howler.js
- **Charts**: Recharts
- **Animation**: Framer Motion

### Getting Started

1. **Prerequisites**
   - Node.js 18.x or later
   - npm or yarn

2. **Installation**
   ```bash
   # Clone the repository
   git clone [repository-url]
   cd harmonia-client

   # Install dependencies
   npm install
   # or
   yarn install
   ```

3. **Development**
   ```bash
   # Start development server
   npm run dev
   # or
   yarn dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.

4. **Available Scripts**
   - `npm run dev` - Start development server
   - `npm run build` - Build for production
   - `npm run start` - Start production server
   - `npm run lint` - Run ESLint
   - `npm run lint:fix` - Fix ESLint issues
   - `npm run format` - Format code with Prettier
   - `npm run clean` - Run lint:fix and format
